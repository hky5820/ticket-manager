# 보유 화면의 양도 티켓 표시

사용자 요청: 보유 화면에서도 양도 티켓을 남기고, 흐림 효과와 대각선 양도완료 표시로 상태를 구분한다.

- `management-view.js`의 보유 필터에 공연일이 지나지 않은 양도 티켓도 포함한다. 전석 취소 티켓은 제외한다.
- 전체 양도 티켓은 카드 본문을 흐리게 하고, 오른쪽 위에 대각선 `양도완료` 띠를 표시한다. 상세 열기와 선택은 유지한다.
- 일부 양도 티켓은 본문을 유지하고 `일부 양도` 표시 및 좌석별 `(양도)` 표기를 사용한다.
- 전체 양도는 `transfer.done`과 좌석별 `t` 플래그를 모두 지원한다.
- 목록과 달력의 카드에 같은 표시를 적용한다. 가장 가까운 공연에는 실제 보유 좌석이 있는 티켓만 사용한다.
- 보유 필터 건수는 표시된 예매 건수다. 헤더 보유 매수, 결산 및 Android 캘린더 동기화는 기존 회계 모델을 유지한다.
- DB의 양도 이력과 수령액을 변경하지 않는다.
- 앱 셸 버전을 v51로 올려 기존 설치에도 갱신한다.

검증: 기존 브라우저 검사에 양도 카드 표시, 상세 열기, 좌석별 전체 양도, 가장 가까운 공연 제외 및 달력 표시를 추가한다. 320/390/1280px 화면과 오프라인 앱 셸을 확인하고 기존 결산 검사를 실행한다.
